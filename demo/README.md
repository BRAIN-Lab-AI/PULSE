# PULSE - Cardiac MRI Segmentation (Demo)

Interactive demo for **PULSE** (IEEE JBHI 2026). Upload a short-axis cine cardiac
MRI (`.nii` / `.nii.gz`) and the model segments the right ventricle, myocardium,
and left ventricle.

- Model weights: [hg-0403/PULSE](https://huggingface.co/hg-0403/PULSE)
- Code and full pipeline (segmentation + diagnosis + report): [github.com/BRAIN-Lab-AI/PULSE](https://github.com/BRAIN-Lab-AI/PULSE)

For research and educational use only; not a medical device.
